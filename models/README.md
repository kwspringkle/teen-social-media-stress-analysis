# models/

Thư mục này lưu các mô hình đã huấn luyện để dùng lại cho dự đoán, so sánh hoặc demo.

## Gợi ý tổ chức

- `ml/`: mô hình machine learning truyền thống như Random Forest, XGBoost, LightGBM.
- `dl/`: mô hình deep learning như MLP hoặc TabNet.

## Quy ước

- Tên file nên phản ánh rõ thuật toán và phiên bản.
- Nên lưu kèm thông tin về feature set, tham số chính, và ngày huấn luyện ở README hoặc metadata riêng.
