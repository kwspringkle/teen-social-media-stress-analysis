# Teen Social Media Stress Analysis

Dự án này phân tích mối liên hệ giữa hành vi sử dụng mạng xã hội và mức độ căng thẳng/tâm lý của thanh thiếu niên. Repository được chia thành các thư mục riêng để tách rõ dữ liệu, mô hình, kết quả và phần trình bày.

## Cấu trúc chính

- [data/](data/README.md): lưu dữ liệu thô và dữ liệu đã xử lý.
- [app/](app/README.md): ứng dụng demo hoặc dashboard tương tác.
- [models/](models/README.md): các file mô hình đã huấn luyện.
- [results/](results/README.md): metrics, dự đoán và kết quả tổng hợp.
- [figures/](figures/README.md): biểu đồ và hình minh họa.
- [report/](report/README.md): nội dung báo cáo theo từng phần.

## Ghi chú

Thư mục này tập trung vào quy trình phân tích dữ liệu, xây dựng mô hình ML/DL, phân cụm hành vi, và giải thích mô hình. Dữ liệu gốc nằm trong [data/raw/](data/raw/README.md), còn dữ liệu sau tiền xử lý được lưu ở [data/processed/](data/processed/README.md).
