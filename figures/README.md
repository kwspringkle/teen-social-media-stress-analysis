# figures/

Thư mục này lưu các hình ảnh và biểu đồ phục vụ phân tích, báo cáo và trình bày kết quả.

## Gợi ý tổ chức

- `eda/`: biểu đồ khám phá dữ liệu.
- `models/`: hình về hiệu năng mô hình, ROC, confusion matrix, feature importance.
- `clustering/`: biểu đồ phân cụm hành vi.
- `explainability/`: biểu đồ giải thích mô hình như SHAP hoặc permutation importance.

## Quy ước

- Ưu tiên đặt tên file mô tả rõ nội dung và nguồn tạo.
- Lưu định dạng nhẹ và dễ dùng cho báo cáo như PNG hoặc SVG.
