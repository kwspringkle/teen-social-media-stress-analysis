# data/processed/

Chứa dữ liệu đã được làm sạch và chuẩn bị cho huấn luyện mô hình, phân cụm hoặc trực quan hóa.

## Có thể bao gồm

- File dữ liệu sau xử lý thiếu dữ liệu và ngoại lệ.
- Dữ liệu đã mã hóa biến phân loại.
- Dữ liệu đã tách train/test hoặc tạo đặc trưng.

## Quy ước

- Mỗi file nên phản ánh rõ bước xử lý hoặc trạng thái dữ liệu.
- Dùng định dạng nhất quán như CSV để dễ đọc lại trong notebook và script.
