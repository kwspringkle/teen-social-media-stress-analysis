# report/

Thư mục này dùng cho nội dung báo cáo cuối cùng và các phần mô tả theo từng giai đoạn của dự án.

## Gợi ý tổ chức

- `sections/`: các file markdown mô tả EDA, tiền xử lý, mô hình, giải thích kết quả.
- `final_report.docx`: báo cáo tổng hợp hoàn chỉnh nếu cần nộp theo định dạng Word.

## Mục đích

- Lưu giải thích, kết luận và nhận xét theo cấu trúc rõ ràng.
- Tách nội dung viết báo cáo khỏi dữ liệu và mã phân tích.
