# results/

Thư mục này chứa đầu ra cuối cùng của các thí nghiệm và chạy mô hình.

## Gợi ý tổ chức

- `metrics/`: bảng chỉ số đánh giá như accuracy, F1, AUC, RMSE hoặc MAE tùy bài toán.
- `predictions/`: file dự đoán trên tập test hoặc tập kiểm tra.
- `clustering/`: kết quả gán nhãn cụm và thống kê cụm.

## Mục đích

- Dễ so sánh giữa các mô hình và pipeline.
- Tách kết quả khỏi mã nguồn để báo cáo và tái sử dụng.
